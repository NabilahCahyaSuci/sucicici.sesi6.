Pengantar Generic Dasar

Generic Dasar adalah konsep dalam pemrograman yang digunakan untuk membuat class atau fungsi yang dapat bekerja dengan berbagai tipe data tanpa harus menulis kode berulang. Dengan generic, tipe data dapat ditentukan saat program dijalankan, sehingga kode menjadi lebih fleksibel, efisien, dan mudah digunakan kembali.

Class Modifiers

Class Modifiers adalah kata kunci dalam pemrograman yang digunakan untuk mengatur bagaimana sebuah class dapat diakses, digunakan, serta diwariskan oleh class lain. Modifier ini membantu menentukan apakah sebuah class bisa dibuat objeknya, bisa diturunkan (inheritance), atau dibatasi penggunaannya. Dengan adanya class modifiers, struktur program menjadi lebih terkontrol, aman, dan mudah dikelola sesuai dengan konsep Object-Oriented Programming (OOP).

Pengantar Generic

Pengantar Generic adalah penjelasan awal mengenai konsep generic dalam pemrograman, yaitu teknik untuk membuat class atau fungsi yang dapat digunakan dengan berbagai tipe data. Generic memungkinkan penulisan kode yang lebih fleksibel dan tidak perlu membuat banyak versi untuk tipe data yang berbeda, sehingga program menjadi lebih efisien dan mudah dikelola.

🔹Masalah Tanpa Generic

Masalah Tanpa Generic adalah kondisi ketika program harus membuat banyak class atau fungsi yang sama hanya untuk menangani tipe data yang berbeda. Hal ini menyebabkan kode menjadi berulang, sulit dikelola, dan kurang efisien. Selain itu, tanpa generic, risiko kesalahan tipe data (type error) juga lebih tinggi karena tidak ada pembatasan tipe yang jelas.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A class Box { dynamic data; Box(this.data); } void main() { var box = Box(42); int value = box.data; // bisa error saat runtime }

🔹 Solusi dengan Generic

Solusi dengan Generic adalah menggunakan konsep generic untuk membuat class atau fungsi yang dapat menangani berbagai tipe data dalam satu kode yang sama. Dengan generic, penulisan kode menjadi lebih ringkas, tidak berulang, dan lebih mudah dikelola. Selain itu, generic juga meningkatkan keamanan tipe data (type safety) karena tipe ditentukan secara jelas, sehingga mengurangi kesalahan dalam program.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A mixin CanFly { bool _isFlying = false; bool get isFlying => _isFlying; void fly() { if (!_isFlying) { _isFlying = true; print('Started flying!'); } else { print('Already flying!'); } } void land() { if (_isFlying) { _isFlying = false; print('Landed!'); } else { print('Already on the ground!'); } } } mixin CanSwim { bool _isSwimming = false; bool get isSwimming => _isSwimming; void swim() { if (!_isSwimming) { _isSwimming = true; print('Started swimming!'); } else { print('Already swimming!'); } } void stopSwim() { if (_isSwimming) { _isSwimming = false; print('Stop swimming!'); } else { print('Already stopped!'); } } } class Bird with CanFly {} class Duck extends Bird with CanSwim {} class Fish with CanSwim {} class Airplane with CanFly {} void main() { Bird bird = Bird(); bird.fly(); bird.land(); print('----------------'); Duck duck = Duck(); duck.fly(); duck.swim(); duck.stopSwim(); print('----------------'); Fish fish = Fish(); fish.swim(); fish.stopSwim(); print('----------------'); Airplane airplane = Airplane(); airplane.fly(); airplane.land(); }

🔹 Sintaks Generic Dasar

Sintaks Generic Dasar** adalah cara penulisan generic dalam pemrograman dengan menggunakan tanda kurung sudut (`< >`) untuk mendefinisikan tipe data yang bersifat fleksibel. Biasanya digunakan simbol seperti `T` sebagai penanda tipe. Dengan sintaks ini, sebuah class atau fungsi dapat digunakan untuk berbagai jenis data tanpa perlu menulis ulang kode, sehingga membuat program lebih efisien, fleksibel, dan mudah dikelola.

🔹 contoh Sintaks Generic pada class dan function

Generic pada class memungkinkan satu class digunakan untuk berbagai tipe data, sedangkan generic pada function memungkinkan satu fungsi menerima berbagai tipe data, sehingga kode lebih fleksibel dan tidak berulang.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A class MyClass { T data; MyClass(this.data); T getData() { return data; } } T myFunc(T value) { return value; } void main() { var myInt = MyClass(10); var myString = MyClass('Test'); print(myInt.getData()); print(myString.getData()); print(myFunc(100)); print(myFunc('Hello')); }

🔹 contoh Kelas Box

Box adalah class generic yang dapat menyimpan berbagai tipe data (seperti int atau String) menggunakan satu struktur yang sama, sehingga lebih fleksibel dan tidak perlu membuat banyak class.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A void handleResponse(ApiResponse response) { switch (response) { case Success(): print("Success: ${(response as Success).message}"); break; case Error(): print("Error: ${(response as Error).errorMessage}"); break; } } void main() { handleResponse(Success("Data berhasil")); handleResponse(Error("Terjadi kesalahan")); } sealed class ApiResponse {} class Success extends ApiResponse { final String message; Success(this.message); } class Error extends ApiResponse { final String errorMessage; Error(this.errorMessage); }

🔹 Multiple Type Parameters

Multiple Type Parameters adalah penggunaan lebih dari satu tipe data dalam generic dengan menuliskan beberapa parameter di dalam tanda `< >`, misalnya ``.Dengan cara ini, sebuah class atau function dapat menangani beberapa tipe data sekaligus, sehingga lebih fleksibel dan efisien tanpa perlu membuat banyak kode terpisah.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A base class Animal { void speak() { print("Hewan bersuara..."); } } base class Dog extends Animal { @override void speak() { print("woof woff!"); } } void main() { Animal myDog = Dog(); myDog.speak(); }

🔹 menggabungkan dua nilai dengan tipe data yang berbeda.

Menggabungkan dua nilai dengan tipe data yang berbeda dapat dilakukan menggunakan generic dengan multiple type parameters, misalnya ``. Dengan cara ini, dua nilai yang memiliki tipe berbeda dapat disimpan atau diproses dalam satu class atau function tanpa harus membuat kode terpisah. Generic akan menjaga tipe data tetap jelas dan aman, sehingga program menjadi lebih fleksibel dan tidak berulang.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A base class Animal { void speak() { print("Hewan bersuara..."); } } base class Dog extends Animal { @override void speak() { print("Woof!"); } } void main() { Animal animal = Dog(); animal.speak(); }

🔹 Generic dengan extends

Generic dengan extends adalah penggunaan generic yang diberi batasan tipe data (constraint), sehingga tipe yang digunakan harus merupakan turunan dari tipe tertentu. Dengan extends, kita bisa memastikan bahwa generic hanya menerima tipe data yang memiliki sifat atau method tertentu, sehingga lebih aman dan terkontrol.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A final class Settings { final String theme; final int fontSize; Settings({required this.theme, required this.fontSize}); void showSettings() { print("Theme: $theme, Font Size: $fontSize"); } } class CustomSettings { final Settings settings; CustomSettings(String theme, int fontSize) : settings = Settings(theme: theme, fontSize: fontSize); void showSettings() { settings.showSettings(); } } void main() { Settings settings = Settings(theme: "Dark", fontSize: 14); settings.showSettings(); CustomSettings custom = CustomSettings("Dark", 14); custom.showSettings(); }

🔹Type Inference (Inferensi Tipe)

Type Inference (Inferensi Tipe) adalah kemampuan bahasa pemrograman untuk menentukan tipe data secara otomatis tanpa harus dituliskan secara eksplisit oleh programmer. Dengan fitur ini, kita tidak perlu selalu menuliskan tipe data karena sistem sudah bisa mengenalinya dari nilai yang diberikan. Hal ini membuat kode lebih ringkas, mudah dibaca, dan tetap aman digunakan.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A sealed class Status { const Status(); } class Loading extends Status { const Loading(); } class Loaded extends Status { final String data; const Loaded(this.data); } class Failed extends Status { final String error; const Failed(this.error); } void handleStatus(Status status) { switch (status) { case Loading(): print('Loading...'); case Loaded(:final data): print('Data: $data'); case Failed(:final error): print('Error: $error'); } } void main() { handleStatus(const Loading()); handleStatus(const Loaded("Data berhasil")); handleStatus(const Failed("Gagal")); }

🔹 Pembatasan Tipe dan manfaatnya

Pembatasan tipe adalah aturan dalam penggunaan generic yang membatasi jenis tipe data yang boleh digunakan, biasanya dengan kata kunci seperti `extends`. Dengan adanya pembatasan ini, keamanan tipe data (type safety) lebih terjaga, kesalahan dalam program dapat dikurangi, serta memastikan bahwa tipe data yang digunakan memiliki fungsi atau sifat tertentu. Hal ini juga membuat kode menjadi lebih terkontrol dan mudah dikelola.

🔹 Pembatasan Tipe pada Interface dan Class

Pembatasan tipe pada interface dan class adalah penggunaan generic dengan batasan tertentu (seperti `extends`) yang diterapkan pada interface atau class agar hanya tipe data tertentu yang dapat digunakan. Dengan pembatasan ini, interface dan class menjadi lebih aman karena hanya menerima tipe yang sesuai, memastikan adanya method atau sifat tertentu, serta membuat kode lebih terstruktur, terkontrol, dan mudah dikelola.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A sealed class AppState {} class LoadingState extends AppState {} class SuccessState extends AppState { final List items; SuccessState(this.items); } class ErrorState extends AppState { final String message; ErrorState(this.message); } void showLoading() { print('Loading...'); } void showItems(List items) { print('Success! Items:'); for (int i = 0; i < items.length; i++) { print('${i + 1}. ${items[i]}'); } } void showError(String message) { print('Error: $message'); } void updateUI(AppState state) { switch (state) { case LoadingState(): showLoading(); case SuccessState(:final items): showItems(items); case ErrorState(:final message): showError(message); } } void main() { updateUI(LoadingState()); updateUI(SuccessState(["Item 1", "Item 2"])); updateUI(ErrorState("Terjadi error")); }

🔹 Pembatasan Tipe dengan Class Abstract

Pembatasan tipe dengan class abstract adalah penggunaan generic dengan batasan `extends` yang mengharuskan tipe data merupakan turunan dari class abstract tertentu. Hal ini memastikan tipe memiliki method atau sifat yang sudah ditentukan, sehingga kode lebih aman, terstruktur, dan tetap fleksibel.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A base class BarangRepository { void create(String barang) { print("Tambah barang: $barang"); } void read() { print("Menampilkan semua barang..."); } void update(int id, String barang) { print("Barang ke-$id diubah jadi $barang"); } void delete(int id) { print("Barang ke-$id dihapus"); } } // subclass beda dari temen base class Gudang extends BarangRepository { @override void read() { print("Daftar barang di gudang:"); } } void main() { print("=== SISTEM GUDANG ==="); Gudang gudang = Gudang(); gudang.create("Sepatu"); gudang.read(); gudang.update(1, "Sepatu Baru"); gudang.delete(1); }

🔹 Generic vs Dynamic vs Object

Generic, dynamic, dan object merupakan tiga cara dalam menangani tipe data dalam pemrograman. Generic bersifat fleksibel namun tetap aman karena tipe data ditentukan dengan jelas saat digunakan (type-safe). Dynamic memberikan kebebasan tanpa tipe tetap, tetapi berisiko menimbulkan error saat program dijalankan. Sementara itu, object dapat menampung semua jenis data, namun penggunaannya kurang praktis karena memerlukan casting untuk mengakses nilai secara spesifik.

Studi Kasus – Cache Generic adalah penggunaan generic untuk membuat cache yang dapat menyimpan berbagai tipe data dalam satu struktur. Dengan cara ini, kode menjadi lebih fleksibel, efisien, dan tetap aman karena tipe data tetap terkontrol.

🔹 Ringkasan

Generic adalah konsep untuk membuat class atau function yang dapat digunakan dengan berbagai tipe data sehingga kode lebih fleksibel dan tidak berulang. Generic ditulis dengan `< >`, bisa menggunakan lebih dari satu tipe, serta dapat dibatasi dengan `extends` agar lebih aman. Selain itu, type inference membantu menentukan tipe data secara otomatis. Sementara itu, class modifiers digunakan untuk mengatur akses dan pewarisan class agar kode lebih terstruktur, aman, dan mudah dikelola.
