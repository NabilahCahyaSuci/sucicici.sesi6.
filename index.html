Pengantar Generic

Generic adalah fitur dalam pemrograman yang memungkinkan class atau fungsi digunakan untuk berbagai tipe data dengan satu kode yang sama, sehingga lebih fleksibel dan efisien.

🔹Masalah Tanpa Generic

Tanpa generic, kode harus dibuat berulang untuk tiap tipe data sehingga terjadi duplikasi dan tidak efisien. Selain itu, penggunaan dynamic membuat tipe data tidak aman karena error baru muncul saat runtime. Hal ini menyebabkan kode lebih sulit dikelola dan rentan kesalahan.

✅ Analisis keberhasilan

Kode berhasil berjalan jika tipe data sesuai atau menggunakan casting (as), sehingga nilai dapat digunakan tanpa error.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A class Box { dynamic data; Box(this.data); } void main() { var box = Box(42); int value = box.data as int; // casting agar aman print(value); }

❌ Analisis kegagalan

Error terjadi karena nilai `"Halo"` (String) dimasukkan ke variabel `int`, sehingga tipe data tidak cocok dan program gagal dijalankan.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas: SI2A class Box { dynamic data; Box(this.data); } void main() { var box = Box("Halo"); int value = box.data; // ERROR saat runtime print(value); }

🔹 Solusi dengan Generic

Solusi dengan Generic adalah menggunakan konsep generic untuk membuat class atau fungsi yang dapat menangani berbagai tipe data dalam satu kode yang sama. Dengan generic, penulisan kode menjadi lebih ringkas, tidak berulang, dan lebih mudah dikelola. Selain itu, generic juga meningkatkan keamanan tipe data (type safety) karena tipe ditentukan secara jelas, sehingga mengurangi kesalahan dalam program.

✅ Analisis keberhasilan

Kode berhasil berjalan karena sudah menggunakan generic (), sehingga tipe data jadi jelas dan aman.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas: SI2A class Box { T data; Box(this.data); } void main() { var intBox = Box(42); var stringBox = Box('Hello'); print(intBox.data); // 42 print(stringBox.data); // Hello }

❌ Analisis kegagalan

Error terjadi karena `stringBox` bertipe `Box`, tetapi diisi dengan nilai `123` (int), sehingga tipe data tidak sesuai.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas: SI2A class Box { T data; Box(this.data); } void main() { var intBox = Box(42); var stringBox = Box('Hello'); int value = intBox.data; stringBox.data = 123; // ERROR }

🔹Masalah Tanpa Generic

Generic ditulis menggunakan tanda `< >` untuk menentukan tipe data pada class atau function. Dengan konsep ini, satu kode dapat digunakan untuk berbagai jenis data tanpa perlu membuat kode baru, sehingga lebih efisien dan mudah digunakan kembali.
  • T = Type
  • E = Element (collection)
  • K = Key
  • V = Value
  • R = Return type

🔹 contoh Sintaks Generic pada class dan function

Generic dapat digunakan pada class dan function dengan menambahkan tanda sebagai parameter tipe data. T merupakan tipe data fleksibel yang akan diganti dengan tipe sebenarnya saat digunakan,Dengan menggunakan generic, satu kode dapat digunakan untuk berbagai tipe data tanpa perlu membuat ulang, sehingga lebih fleksibel dan efisien.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A class MyClass { T data; MyClass(this.data); T getData() { return data; } } T myFunc(T value) { return value; } void main() { var myInt = MyClass(10); var myString = MyClass('Test'); print(myInt.getData()); print(myString.getData()); print(myFunc(100)); print(myFunc('Hello')); }

🔹 contoh Kelas Box

Kelas Box menggunakan generic sebagai tipe data fleksibel. T akan diganti dengan tipe tertentu saat objek dibuat, seperti int atau String. Variabel data menyimpan nilai sesuai tipe tersebut,Dengan generic, satu class bisa digunakan untuk berbagai tipe data tanpa perlu membuat ulang, sehingga lebih efisien dan reusable.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Box { T? _value; Box(this._value); T? get value => _value; void setValue(T value) { _value = value; } } void main() { var intBox = Box(10); print(intBox.value); intBox.setValue(20); print(intBox.value); var stringBox = Box('Hello'); print(stringBox.value); }

🔹 Multiple Type Parameters

Multiple Type Parameters adalah penggunaan lebih dari satu tipe data dalam generic dengan menuliskan beberapa parameter di dalam tanda `< >`, misalnya ``.Dengan cara ini, sebuah class atau function dapat menangani beberapa tipe data sekaligus, sehingga lebih fleksibel dan efisien tanpa perlu membuat banyak kode terpisah.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Pair { K key; V value; Pair(this.key, this.value); void printPair() { print('Key: $key, Value: $value'); } } void main() { var pair1 = Pair('age', 30); pair1.printPair(); var pair2 = Pair('name', 'Alice'); pair2.printPair(); }

🔹 menggabungkan dua nilai dengan tipe data yang berbeda.

Menggabungkan dua nilai dengan tipe data yang berbeda dapat dilakukan menggunakan generic dengan multiple type parameters, misalnya ``. Dengan cara ini, dua nilai yang memiliki tipe berbeda dapat disimpan atau diproses dalam satu class atau function tanpa harus membuat kode terpisah. Generic akan menjaga tipe data tetap jelas dan aman, sehingga program menjadi lebih fleksibel dan tidak berulang.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A String combine(T value1, U value2) { return '$value1, $value2'; } void main() { print(combine('Number', 10)); print(combine(10, 20.5)); }

🔹 Generic dengan extends

Generic dengan extends adalah penggunaan generic yang diberi batasan tipe data (constraint), sehingga tipe yang digunakan harus merupakan turunan dari tipe tertentu. Dengan extends, kita bisa memastikan bahwa generic hanya menerima tipe data yang memiliki sifat atau method tertentu, sehingga lebih aman dan terkontrol.

✅ Analisis keberhasilan

Kode berhasil karena menggunakan generic dengan batasan tipe (T extends num), sehingga hanya tipe angka yang boleh digunakan.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas: SI2A class NumberBox { T value; NumberBox(this.value); T getValue() { return value; } } void main() { var intBox = NumberBox(10); var doubleBox = NumberBox(3.14); print(intBox.getValue()); print(doubleBox.getValue()); }

❌ Analisis kegagalan

Error muncul karena String tidak sesuai dengan batasan T extends num, sehingga tidak bisa digunakan pada NumberBox.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A class NumberBox { T value; NumberBox(this.value); } void main() { var stringBox = NumberBox("Hello"); // ❌ ERROR print(stringBox.value); }

🔹Type Inference (Inferensi Tipe)

Type Inference (Inferensi Tipe) adalah kemampuan bahasa pemrograman untuk menentukan tipe data secara otomatis tanpa harus dituliskan secara eksplisit oleh programmer. Dengan fitur ini, kita tidak perlu selalu menuliskan tipe data karena sistem sudah bisa mengenalinya dari nilai yang diberikan. Hal ini membuat kode lebih ringkas, mudah dibaca, dan tetap aman digunakan.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A T myFunc(T value) { return value; } void main() { var a = myFunc(10); var b = myFunc("Hello"); print(a.runtimeType); // int print(b.runtimeType); // String }

🔹Pembatasan Tipe dan manfaatnya

Pada Dart, pembatasan tipe digunakan untuk memastikan bahwa generic hanya menerima tipe data tertentu yang sesuai.
  • Manfaatnya:
  • Mencegah kesalahan tipe data (lebih aman).
  • Membuat kode lebih jelas dan mudah dibaca.
  • emastikan hanya tipe yang sesuai yang bisa digunakan.
  • Membantu penulisan kode lebih terstruktur.

🔹 Pembatasan Tipe pada Interface dan Class

Pembatasan tipe pada interface dan class adalah penggunaan generic dengan batasan tertentu (seperti `extends`) yang diterapkan pada interface atau class agar hanya tipe data tertentu yang dapat digunakan. Dengan pembatasan ini, interface dan class menjadi lebih aman karena hanya menerima tipe yang sesuai, memastikan adanya method atau sifat tertentu, serta membuat kode lebih terstruktur, terkontrol, dan mudah dikelola.

✅ Analisis keberhasilan

kode berhasil karena semua argumen sesuai dengan batasan Iterable, jadi bisa di-loop tanpa masalah.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A void printIterable>(T data) { for (var item in data) { print(item); } } void main() { printIterable>([1, 2, 3]); printIterable>({'Melon', 'Apple'}); }

❌ Analisis kegagalan

Error terjadi karena fungsi mengharapkan data yang bisa di-iterasi (Iterable), tapi kamu memberi int.
// Nama : Nabilah Cahya Suci // NIM : 251410028 // Kelas : SI2A void printIterable(dynamic iterable) { for (var item in iterable) { print(item); } } void main() { printIterable(10); // Error saat runtime }

🔹 Pembatasan Tipe dengan Class Abstract

Pembatasan tipe dengan class abstract adalah penggunaan generic dengan batasan `extends` yang mengharuskan tipe data merupakan turunan dari class abstract tertentu. Hal ini memastikan tipe memiliki method atau sifat yang sudah ditentukan, sehingga kode lebih aman, terstruktur, dan tetap fleksibel.

✅ Analisis keberhasilan

Kode berhasil berjalan karena tipe data dibatasi dengan benar, sehingga semua objek pasti punya method yang dibutuhkan.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A abstract class Animal { void makeSound(); } class Dog implements Animal { @override void makeSound() { print('Woof!'); } } class Cat implements Animal { @override void makeSound() { print('Meow!'); } } class AnimalCage { T animal; AnimalCage(this.animal); void sound() { animal.makeSound(); } } void main() { var dog = AnimalCage(Dog()); dog.sound(); var cat = AnimalCage(Cat()); cat.sound(); }

❌ Analisis kegagalan

Kode Error karena memakai String pada generic yang hanya menerima turunan Animal.
// Nama : Nabilah cahya suci // NIM : 251410018 // Kelas : SI2A abstract class Animal { void makeSound(); } // Tetap pakai pembatasan tipe class AnimalCage { T animal; AnimalCage(this.animal); } void main() { var stringCage = AnimalCage('test'); // ERROR }

🔹 Praktik 1 – Generic Class & Fungsi

Praktik 1 – Generic Class & Fungsi adalah latihan untuk memahami penggunaan generic pada class dan function agar dapat menangani berbagai tipe data, sehingga kode lebih fleksibel, tidak berulang, dan tetap aman.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Repository { final List _items = []; // Method save void save(T item) { _items.add(item); } // Method getById (pakai index sebagai id sederhana) T? getById(int id) { if (id >= 0 && id < _items.length) { return _items[id]; } return null; } // Method getAll List getAll() { return _items; } } // Fungsi generic swap void swap(List list, int i, int j) { T temp = list[i]; list[i] = list[j]; list[j] = temp; } // Class Triple class Triple { A first; B second; C third; Triple(this.first, this.second, this.third); } void main() { // ===== Repository ===== var repo = Repository(); repo.save("Data 1"); repo.save("Data 2"); print("Semua data: ${repo.getAll()}"); print("Data ke-1: ${repo.getById(0)}"); // ===== Swap ===== List angka = [1, 2, 3, 4]; swap(angka, 0, 3); print("Setelah swap: $angka"); // ===== Triple ===== var triple = Triple("Hello", 10, true); print("Triple: ${triple.first}, ${triple.second}, ${triple.third}"); }

🔹Generic vs Dynamic vs Object

  • Manfaatnya:
  • Generic, Tipe data sudah ditentukan sejak awal, sehingga lebih aman dan tidak perlu konversi saat digunakan.
  • Dynamic, Tipe data bisa berubah-ubah, fleksibel digunakan, tetapi berisiko error saat program berjalan.
  • Object, Bisa menyimpan berbagai tipe data, namun perlu penyesuaian tipe (casting) saat digunakan.

// Contoh perbedaan Box box1 = Box(42); // Generic: aman dynamic box2 = 42; // Dynamic: tidak aman Object box3 = 42; // Object: perlu casting

🔹 Studi Kasus – Cache Generic

Studi Kasus – Cache Generic adalah penggunaan generic untuk membuat cache yang dapat menyimpan berbagai tipe data dalam satu struktur. Dengan cara ini, kode menjadi lebih fleksibel, efisien, dan tetap aman karena tipe data tetap terkontrol.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Cache { final Map _storage = {}; void set(String key, T value) { _storage[key] = value; } T? get(String key) { return _storage[key]; } void remove(String key) { _storage.remove(key); } } class Product { String name; int price; Product(this.name, this.price); } void main() { var userCache = Cache(); userCache.set('name', 'Alice'); var productCache = Cache(); productCache.set('p1', Product('Laptop', 1000)); }

🔹 Ringkasan

Generic adalah konsep untuk membuat class atau function yang dapat digunakan dengan berbagai tipe data sehingga kode lebih fleksibel dan tidak berulang. Generic ditulis dengan `< >`, bisa menggunakan lebih dari satu tipe, serta dapat dibatasi dengan `extends` agar lebih aman. Selain itu, type inference membantu menentukan tipe data secara otomatis. Sementara itu, class modifiers digunakan untuk mengatur akses dan pewarisan class agar kode lebih terstruktur, aman, dan mudah dikelola.

🔹 Latihan

Latihan ini bertujuan memahami penggunaan generic agar kode lebih fleksibel. `Stack` digunakan untuk struktur data LIFO dengan operasi push, pop, dan peek. `mergeLists` berfungsi menggabungkan dua list dengan tipe yang sama. `Response` digunakan untuk menyimpan data dan error secara fleksibel. Sedangkan repository generic adalah sistem pengelolaan data yang dapat digunakan kembali untuk berbagai tipe tanpa menulis ulang kode.
// Nama : Nabilah Cahya Suci // NIM : 251410018 // Kelas : SI2A class Stack { List data = []; void push(T value) { data.add(value); } T pop() { return data.removeLast(); } T peek() { return data.last; } } List mergeLists(List a, List b) { return a + b; } class Response { T? data; String? error; Response({this.data, this.error}); } void main() { var s = Stack(); s.push(1); s.push(2); s.push(3); print(s.peek()); print(s.pop()); print(s.peek()); var a = [1, 2]; var b = [3, 4]; print(mergeLists(a, b)); var r1 = Response(data: "ok"); var r2 = Response(error: "gagal"); print(r1.data); print(r2.error); }
